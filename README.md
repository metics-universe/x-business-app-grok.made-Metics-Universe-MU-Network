## 🌐 Getting Started & Deployment (GitHub Pages)

To view or deploy this application live using **GitHub Pages**:

1. Ensure your repository source branch is set to `main` (or `master`) under your repository **Settings > Pages**.
2. If you are experiencing a `404 File Not Found` error, ensure that your primary entry HTML file is correctly linked or renamed to **`index.html`** in the root directory so GitHub Pages can automatically parse and launch it.
3. Once configured, your app will be accessible via your designated GitHub Pages URL.
